# ADR 0001: Growth experiment is the core object

- Status: accepted
- Date: 2026-08-05

## Decision

Afterplay organizes work around a growth experiment containing a diagnosis, audience, testable hypothesis, plan, outputs, creator decisions, distribution, results, learning, and next move.

## Why

This object connects strategy, production, performance, and memory into one legible loop. It prevents the platform from reading as a bundle of AI features or a contextual clipper.

## Consequences

- Every primary product area presents a different view of the same experiment lifecycle.
- Studio assets and Audience results must remain traceable to an experiment.
- The judge path demonstrates one full experiment rather than many disconnected capabilities.
